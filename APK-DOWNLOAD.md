# APK-Download

Dieser Branch enthält **nur** eine gebaute Release-APK zum direkten Download auf
dem Smartphone — er ist nicht zum Mergen gedacht.

- Datei: `ToDo-md-arm64-release.apk` (arm64-v8a, debug-signiert)
- Passt auf praktisch alle modernen Android-Geräte.

## Installation
1. Auf dem Handy diese Datei über GitHub öffnen und herunterladen
   (Button „Download" / „View raw").
2. Im Dateimanager öffnen, „Installieren aus unbekannten Quellen" erlauben.
3. App starten → „Vault-Ordner wählen" → deinen Obsidian-Vault auswählen.

Der zugehörige Quellcode liegt im PR-Branch
`claude/obsidian-kanban-mobile-app-vkwzvq`.
